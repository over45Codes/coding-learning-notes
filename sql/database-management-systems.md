# Database Management Systems

database management system (DBMS)
Enter the database management system (DBMS). A DBMS carries out several important functions, including the following:

Creating databases and database tables
Entering new data
Deleting outdated data
Exporting necessary information according to specified conditions
Ensuring safe access to your data


How to code a new query search 

SELECT *
FROM playlist;

SQL Comments: Simply put, SQL comments are notes in the code that will be ignored. You can write whatever you want, and they won't affect the output. Let's look at them now.

 A single-line comment starts with --: 

-- This is an SQL comment! Hello, Earth!

And if we want to write a comment that's longer than one line, we can put /* at the beginning and */ at the end of the note.

/* This is not 
a strange poem,
actually, it's
an SQL comment too! */
